Projeto acadêmico com dados sintéticos

Quanto da energia consumida por uma máquina está realmente relacionado à produção?
Essa foi a pergunta que utilizei para desenvolver um projeto de análise de dados aplicado a um processo industrial.

Desenvolvi modelo relacional com tabelas fato (vendas, produção, manutenção, energia) e tabelas dimensão (clientes, produtos, equipamentos) 
através de chaves primárias e estrangeiras utilizando para modelagem e análise o Power Pivot.

Foram feitas tabelas dinâmicas de:
•	kWh/peça; 
•	Quantidade de produtos produzidos por equipamento; 
•	Quantidade de produtos vendidos por segmento; 
•	Quantidade de refugos por turno; 
•	Horas de Paradas por Tipo de Manutenção; 
•	Horas Paradas por Equipamento de Acordo com a Criticidade.
